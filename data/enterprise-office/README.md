# 企业办公模拟材料

衡川数智是虚构企业，全部员工、项目、成果、服务单及反馈均为合成数据，不含真实经营或个人信息。当前数据截点是 **2026-10-21**；覆盖2026年第三季度与第四季度截至该日的累计记录，第四季度并未结束。

共40份可直接导入系统的CSV/TXT，20,520条记录。技术部80人/28项目、研发部56人/22项目、运营部40人/18项目、行政部24人/12项目，共200名模拟人员和80个项目。人员有入离职变化；不同期间出现人数不同。每个部门、期间各5份材料，名称带部门和期间，不会相互覆盖。

| 材料 | 记录数 | 业务关系 |
| --- | ---: | --- |
| 项目进度 | 1,360 | 同一项目按周及期末留快照，包含责任人、组别、进度、计划时间、实际完成日、风险及阻碍 |
| 人员考勤 | 15,203 | 人员与项目关联，在岗期间按虚构企业工作日登记，保留请假、缺勤、迟到及超计划工时 |
| 成果记录 | 217 | 需求评审、阶段交付、验收交接各有唯一编号，关联项目和证据 |
| 服务满意度 | 3,628 | 反馈关联受理/办结服务单，含五分制评分、渠道、评论和无效样本原因 |
| 工作说明 | 112 | 各部门的范围、口径、风险、复盘、计划和未提供数据的边界 |

日历采用虚构周一至周五排班，不套用法定节假日和调休；反馈不是全部服务单或全体员工意见；超计划工时不等于审批加班；不提供收入、成本、同比基线等未模拟指标。项目快照不是重复项目，跨期间继续存在的项目编号用于追踪，不重复累计为新项目。业务主键在文件间唯一：项目编号+快照日、人员编号+日期、成果编号、反馈编号。

## 在当前工作台运行

这些文件已导入正常8520工作台，不需要重新生成或切换空间。材料库搜索“技术部_2026Q3”，选择5份文件，点击“规划汇报”，可以留空规划重点；查看方案后确认即可。也可新建报告选择相同5份材料，并提交：

> 请生成2026年第三季度技术部工作汇报，使用所选材料，包含工作概况、项目进度、人员考勤、成果统计、服务满意度、问题风险与后续安排，标明样本范围，不编造未提供的经营数据，输出Markdown和PDF。

第三季度技术部可核对：项目28个，其中完成12个、暂停2个、进行中14个；考勤4,904人日、成果68条、有效满意度反馈723条。材料总行数不能当成项目数；出勤率等指标须遵循系统统计口径。

第四季度实验可搜索“技术部_2026Q4”，选择5份，输入：

> 请生成技术部2026-10-01至2026-10-22（结束日不含）的阶段工作汇报，数据截至10月21日，包含项目进度、人员考勤、成果和服务满意度，不推算第四季度整季结果。

先用离线模式验证，不消耗模型额度；真实模式由用户主动提交后才调用已配置模型。

## 复现与导入

在项目根目录执行：

```bash
.venv/bin/python data/enterprise-office/generate.py
.venv/bin/python data/enterprise-office/import_materials.py
```

生成器仅重建当前目录中的公开模拟文件，不清空运行数据，也不自动导入。导入器调用现有本地材料接口，以内容SHA256、分类、部门和期间检查已存在项；重复执行跳过已有材料，不增加版本或暂存文件。`manifest.json`记录每个文件的校验值、行数、范围以及8个部门/期间组合的核对预期。旧`data/office-cases`和`data/demo`回归材料保持原样。
