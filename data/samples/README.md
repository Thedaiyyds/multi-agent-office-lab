`issues.txt` 在任何合法查询中均作为 `scope=unfiltered` 材料原样返回，不代表查询部门或季度的已筛选问题。自然行不等于结构化业务记录，其来源元数据 `record_count=0`，不推算问题条数。任意源文件有校验错误时，结果为 `invalid_data`，不产生指标，也不返回问题原文。
