# 报告任务与执行历史

报告任务页每份报告只显示一个入口。重新执行同一报告会增加详情中的执行历史，不会在主列表增加一份同名报告。新提交且尚未确认的材料方案显示为“待确认方案”；确认后原任务接续生成，转为对应报告入口。

没有形成报告的补充信息、失败、取消或中断记录统一放在折叠的“未成稿尝试”。原文、所选文件、运行模式及是否规划相同的重复提交合并展示；展开可以进入每次真实执行的过程与失败原因。原始记录完整保留，不合并或改写运行结果。

列表支持按标题/部门搜索、状态及运行模式筛选，主列表每页10项，未成稿尝试每页5组。进入一份报告后，展开“执行历史”查看它的历次运行，每页5次；运行详情仍展示五角色节点、结果、用量和错误。

勾选已结束的任务后点击“收起所选任务”，可整理旧记录。勾选“显示已收起”后可选择并恢复。收起不会删除材料原文件、报告、导出文件或执行证据；任务有新进展时自动重新显示。处理中及待确认方案不能收起。此操作仅影响当前工作区的任务列表。

同一份报告的多次执行会合并入口；不同提交创建的不同报告保留独立入口，标题相同不代表内容相同，不会自动合并。工作台近期报告和报告归档仍可访问既有报告。列表接口只返回摘要，不传输每次运行的大量事实、原始节点或来源明细；打开运行详情时才读取这些证据。
