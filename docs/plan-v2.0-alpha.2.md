# v2.0-alpha.2 材料接入开发计划

2026-10-16。用户已授权按实验指导书功能基线恢复下一版开发，并要求可隔离演示的例子和操作教学。

## 本版目标

保留现有界面和架构，完成TXT、CSV、DOCX、简单本地接口的导入、来源预览、字段映射、校验、版本与重复确认防重。当前版本不计算业务指标，不运行五角色，不提供Markdown/PDF生成；这些功能仍按原阶段实施。

## 文件分工

| 角色 | 独占范围 | 工作 |
| --- | --- | --- |
| 材料后端Agent | workbench/materials.py、test_workbench_materials.py | 三格式解析、导入草稿、确认、版本、去重及安全边界 |
| 前端Agent | Materials.tsx、api.ts、App.tsx、styles.css | 原材料页接入真实上传、映射、预览、错误、历史与演示入口 |
| 独立质量Agent | data/demo、演示指南、审查记录、test_workbench_demo.py | 合成案例、操作教学、隔离测试和交叉审查 |
| 主协调者 | api.py、demo.py、依赖与启动、发布记录 | 契约、集成、本地接口、隔离演示服务、浏览器验收、PR/CI/merge/tag |

## 接口和存储

`X-Workspace`继续区分normal/demo。上传文件以multipart进入`POST /api/v1/materials/import`；返回导入草稿，预览最多20条，确认时对全部内容校验。`POST /api/v1/imports/{id}/confirm`以映射和范围确认入库。材料列表、详情和原件下载统一校验空间，客户端不能提交服务器路径。

原件使用服务端生成的路径与内容哈希，确认创建不可变版本。同文件、分类、映射和范围去重，同名修正形成新版本。确认先全量校验再事务保存，不允许部分脏数据入库。临时导入与材料目录位于所选数据库旁，均在Git忽略的outputs内。

`GET /api/v1/demo/provider/{kind}`提供只读模拟数据接口；`POST /api/v1/materials/from-demo-api`将其冻结为导入草稿；`POST /api/v1/demo/load`复用同一解析确认逻辑显式加载技术部案例。演示端点只对demo空间开放，不接收任意远程URL。

## 演示与开发隔离

正常服务为8520、outputs/workbench；演示服务为8530、outputs/demo。案例源文件只读保存在data/demo，全部标明合成模拟。自动测试只使用tmp_path数据库，不能读写正常或演示持久库。重复加载按内容去重，不清空、不覆盖用户数据；没有危险的重置按钮。

演示指南提供启动命令、点击顺序、应看到的结果、说明词、失败处理和后续完整项目演示的阶段边界。

## 交付门槛

1. 三种中文文件可导入，表格/段落/CSV行定位可读；字段映射可修改，异常逐项说明。
2. 错误映射、坏编码、异常日期/数值、冲突记录、伪DOCX及超限文件不能创建确认材料。
3. 去重、不可变版本、跨空间拒绝、重启持久和下载字节一致性通过测试。
4. 技术案例重复加载不增加材料，正常空间保持独立；独立演示DB不影响正常DB。
5. 真实浏览器验收上传/映射/确认/去重/错误和390px布局；DOCX样例渲染检查。
6. 锁定安装、Python/前端测试、Ruff/构建、旧版离线验收通过，交叉审查关闭阻断问题后PR、CI、merge、tag。

本版默认不新增付费模型调用。演示材料与内部日志不冒充真实部门业绩或新版完整Agent运行证据。
