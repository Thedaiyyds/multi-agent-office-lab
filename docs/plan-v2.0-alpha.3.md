# v2.0-alpha.3 开发计划

依据[实施说明书R2](proposals/v2.0-review/implementation-spec-r2.md)，先完成数据统计与来源核对，再直接进入已授权后续阶段。目标是在正常报告工作区选择已确认材料、生成并查看统计快照。本版统计不调用模型，五角色与导出尚待alpha.4—5，不能称整体完成。

| 分工 | 文件范围 | 内容 |
|---|---|---|
| 需求复核Agent | 只读 | 原指导书、R1/基线冲突核对、实施边界审查 |
| 数据后端Agent | statistics.py、test_workbench_statistics.py | 全量记录、四组统计、来源、冻结快照及接口 |
| 前端Agent | Statistics.tsx、App.tsx、api.ts、styles.css | 普通材料选择、统计组、可选考勤清单、结果/限制/历史/来源 |
| 主协调者 | R2、api集成、版本、额外测试、发布 | 契约、独立手算核对、浏览器验收、CI/PR/merge/tag |

步骤：1.确认R2指导书映射；2.确定API与政策；3.后端和前端并行实现；4.独立审查边界和业务数字；5.真实浏览器在8520正常流程验证材料选择、统计与来源；6.锁文件安装、全仓回归、构建、旧版离线验收；7.PR/CI/merge/tag，继续下一阶段。

接口与字段详见R2。统计快照不可变并绑定报告版本；报告修改后显示过期，不能当本版当前事实。冲突记录不能静默覆盖；缺组材料显示needs_input，数值未定义用null。正常与历史demo工作空间访问校验延续，不新增空间或服务。

必要测试：跨文件去重和冲突、同系列多个版本、所有行参与计算、跨部门/日期边界、最新项目快照、完成日期缺失、考勤缺值/零分母/样本与完整覆盖、多量表和无效反馈、来源集合、快照持久化与旧版本提示、跨空间访问与版本409。案例只读，测试写临时库，无模型费用。
