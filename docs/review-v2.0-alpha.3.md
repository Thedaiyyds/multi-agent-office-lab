# v2.0-alpha.3 审查记录

2026-10-16。依据指导书2.3、5.2.3、5.3.3、5.4.3、教师补充和用户最新授权。需求Agent独立只读核对原DOCX与R1/基线，确认R2已明确消解强制人工门槛、Word必做、独立演示等冲突，可直接继续开发；不需要用户重新决定框架或顺序。

## 数据与界面交叉审查

数据后端Agent负责statistics.py与48个统计测试；前端Agent负责报告工作区统计组件、接口类型及样式；独立审查Agent直接读取普通CSV原件调用纯计算器手算核验，并独立执行48个测试；协调者集成和验证浏览器及全仓回归。

发现并修复：

1. 考勤缺少清单时只支持样本，不得把28/32称整个季度出勤率。明确roster×dates清单契约，缺行/缺值时仍计算完整人日覆盖率，整体率须全部覆盖且计划>0。
2. 可选整体考勤指标未定义不应让已有样本组完全不可用；整体率null附限制，已有样本仍ready。明确清单却不完整时needs_input。
3. 请假工时不能从输出消失，增加样本请假合计，缺字段为null而不是0，且不扣分母。
4. 满意度全部明确无效时，有效数为0、均分为null；完全没有范围记录时缺失不当0。
5. 成果缺少可选关联项目与空关联归一，避免完全相同业务记录产生伪冲突。

独立审查无剩余阻断项。该结论仅为统计阶段，不证明完整实验已完成。正常入口本地接口和五角色链路属于alpha.4，报告导出属于alpha.5。最终发布验证见本版发布记录。
