# v2.0-alpha.6 场景与复现验收计划

2026-10-17。alpha.5已通过PR #14双CI、合并并标记版本。依据R2继续，不改变框架、8520入口、五角色或Markdown/PDF格式。

1. 前端Agent关闭报告归档占位，复用现有合格报告查询和交付面板，实现搜索、空态/错误恢复、独立交付页；修复首次交付的列表缓存竞态。
2. 主协调者执行技术Q2、行政Q1两个普通材料场景的真实模型验收。每场景最多8请求、3648预留输出token，最多一次返工；逐场检查，不自动反复重试。保留失败证据与总用量，不把offline_mock当实际供应商成功。
3. 后端审查Agent复核模型上下文优化：最终Manager接收完整正文/事实表/限制和材料索引、完整稿SHA，避免重复发送逐行SHA附录；程序校验与最终产物不变。既有saved_report明确逐字段复制。
4. 独立验收Agent在临时DB测试真实PDF生成、重启读取、修改双角色复审；无.env的源码副本锁依赖安装复现，更新部署与普通案例教程，不新增演示系统。
5. 主协调者检查真实页面归档、合格报告、双文件与来源，保存截图。完整回归及CI通过后按PR→merge→tag；随后正式版收束课程报告、搭建过程、运行截图和最终发布。

退出条件：正常两场景闭环及历史读取可解释；归档有实际数据；安装不依赖用户密钥或私有路径；源码副本可离线模型运行及导出；真实失败不伪装通过。正式版本另补最终课程报告，不覆盖历史v1报告。
