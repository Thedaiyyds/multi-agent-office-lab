# v2.0 课程提交与现场使用

代码仓库：https://github.com/Thedaiyyds/multi-agent-office-lab。正式版本以v2.0.0标签及发布PR为准。

提交文件：docs/report/experiment-report-v2.docx为可编辑实验报告，experiment-report-v2.md为源稿；architecture-analysis-v2.md为架构分析。姓名、学号、班级和指导教师留空，按课程实际信息填写。不要提交.env、密钥、outputs个人数据或.venv。

正常启动：按docs/deployment-v2.0.md运行bash scripts/start_workbench.sh，打开http://127.0.0.1:8520。按docs/report-example.md复制一段技术部需求，明确勾选本地样例数据并选择真实或离线模式，再开始协作。无需另建演示空间或切换端口。

现场顺序：一段需求→五角色实际节点→统计来源和样本限制→Checker及Manager→正文和MD/PDF下载→修改文字、保存新修订、两角色复审→历史与归档。已有真实验收结果可从归档回看，不必为展示重复消耗API。

最终两场景文件在evidence/v2.0.0/technical-final.md/.pdf与administration-final.md/.pdf；实际运行与用量见同目录validation.json及alpha.6安全run证据。它们是公开合成业务样例，不是企业真实记录。课程报告已记录真实单人开发与AI协作，不等于三名人类组员；教师组队要求应按实际课程安排处理。
