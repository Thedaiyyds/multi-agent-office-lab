# v0.6 网页使用

在仓库根目录安装并启动：

```bash
uv sync --locked --python 3.12
uv run --locked streamlit run app.py --server.address 127.0.0.1
```

打开终端显示的本机网址，默认 http://127.0.0.1:8501 。仓库配置上传大小2MiB/文件、关闭Streamlit使用统计，服务绑定本机。页面复用 v0.5 的核心图、统计与最终导出门禁。服务持续运行期间可使用浏览器；停止服务使用启动终端的 Ctrl+C。

## 样例与上传

默认选择离线模拟与样例数据，输入“生成研发部2026年第二季度工作报告”，开始运行后查看真实节点记录、指标、大纲、审核和报告。正常样例指标是项目3、完成2、完成率2/3、成果2；2/3是项目完成率。样例和本地模型脚本明确标记，不是新增真实模型运行证据。

上传需要三个同名文件 projects.csv、achievements.csv、issues.txt，使用UTF-8（允许BOM），每文件不超过2MiB，CSV最多10,000记录、字段和业务值遵循 [数据契约](data-contract.md)。上传类型筛选不是内容校验；页面在开始模型前复用完整数据校验，拒绝错误字段、非法数据、路径/未知/重复名及缺文件。空TXT允许，合法无匹配记录由工作流返回needs_input。自有材料标记“用户提供数据”，不冒充模拟数据。

提交时冻结输入字节，在隔离临时目录执行；过程中更换上传或样例不会改写已接纳运行。临时文件结束清理，实际节点与来源摘要按run_id保存到本地outputs/web；报告及审计可能包含自有材料，请按需要自行保留或脱敏，自动outputs默认不提交Git。

## 运行、返工与下载

同一浏览器会话一次只接纳一个任务。任务接纳后后台继续运行，页面只轮询快照，不重新调用模型；重复提交、页面重运行、下载不会追加请求。任务终止后点击“新建任务”才可以再次提交；运行期间不能重置。新建浏览器会话或服务器重启没有持久恢复保证。

进度来自实际node_started/node_finished事件，显示角色及返工轮次。节点内的HTTP与工具事件在该节点结束后公布，当前角色运行时间不是完成率预测。mock很快时页面可能直接看到终态，其日志仍保留实际顺序。

默认两次业务返工、零网络重试，最多10次HTTP和4032预留输出；高级选项可下调预算，输入token另计。业务返工与网络重试分别显示；未知模型usage为不可用，mock不虚构付费用量。故障实验须明确选择，bad-fact/missing-section仅初轮注入，always-bad每轮注入。原生成结果与注入标记均保存，不能冒充模型自然错误。

completed且最终门禁通过才显示和下载最终Markdown。needs_input、review_failed、failed保留过程和已有草稿，不提供最终报告；失败/预算不足时可以查看实际已有意见。初稿与每轮修改都有自己的审核状态，未完成审核的版本明确待审核。下载的内容来自本次导出产物，不重新生成。

## 真实模型

页面显式选择真实模式时使用本地.env配置。密钥继续只在本地填写，页面无密钥输入或展示。DeepSeek profile关闭思考、默认零网络重试、使用共享请求与输出预算；真实提交会消耗模型用量，查看已生成记录和下载不调用模型。

v0.5的真实接入与返工证据见 [原验收记录](validation-v0.5.md)。v0.6是否新增真实付费调用以 [本版验收](validation-v0.6.md) 为准，不能把旧API结果或mock页面截图当作本版真实API验收。受约束正文仅保证本次检查覆盖的事实，未来建议仍需人工评估。

网页版为本机课程原型，没有账号权限、公网保护、跨进程队列、服务器重启恢复或PDF导出。实验截图只来自实际网页捕获，最终课程报告另行整理。
