# v2.4.0：跨范围材料规划与任务整理

选择跨部门、跨期间的材料而不填规划重点时，旧实现会在Manager调用前要求补充唯一范围，Planner无法提出方案。本版默认提供综合工作汇编，同时提供各部门、期间的单独方向；可修改方案并确认后继续生成。显式选择较长期间时，按所提供材料实际覆盖范围规划，缺少的完整性依据继续披露。

Data按方案确认的各个实际范围独立调用现有统计工具，指标、文字引用与来源注明所属范围；不把不同期间、部门的项目数、满意度或出勤率混为一个数。Writer消费分组后的事实与大纲，Checker检查归属，Manager最终验收，输出Markdown和PDF。综合报告再次执行时保留已确认范围。同一任务仍按Manager→Planner→用户确认→Data→Writer→Checker→Manager验收推进；直接生成入口保持自动流程。

报告任务改为每份报告一个入口，执行历史收在报告详情中，默认折叠、每页5次。未确认的方案显示为一个待确认任务，确认后转为报告入口；没有成稿的相同提交合并展示在折叠的“未成稿尝试”中，仍可查看每次真实运行。主列表增加搜索、状态/模式筛选、每页10项，以及可恢复的“收起任务”。不自动合并标题相同的不同报告，不删除原材料、报告或运行证据。摘要接口避免列表下载大量统计明细和完整节点。

本版仅增加列表显示偏好表，兼容既有报告、材料、运行及旧待确认方案。继续使用8520、原文件工作目录、LangGraph五角色和既有双格式交付，不引入新依赖。[规划说明](../material-report-planning.md) · [任务整理说明](../report-task-management.md)。

验证使用临时数据库、离线模型和本地HTTP脚本，不调用付费模型。新增检查覆盖跨部门/期间、同部门跨季度、宽期间、重复日期表达、方向切换、确认与再次执行、来源归属、实际双格式下载、重复尝试聚合、收起/恢复、新活动重新显示、活动任务限制和工作区隔离。最终验证记录见[验证摘要](../validation-v2.4.0.md)。
