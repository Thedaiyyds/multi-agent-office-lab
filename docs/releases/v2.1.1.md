# v2.1.1 报告任务界面精简

2026-10-20。用户要求移除报告任务的需求版本显示、辅助需求草稿编辑和独立统计核对入口，让操作聚焦实际办公汇报。本版采用前端精简，不迁移或改写既有业务数据。

## 变化

- 报告任务标题旁只显示业务状态，取消内部需求版本号。未形成合格报告的草稿状态改显示“待生成”。
- 删除“辅助编辑：报告需求草稿”和“辅助核对：统计与数据来源”，移除未再使用的DraftForm、Statistics组件及专用样式、未保存草稿阻断提示。
- 待生成任务直接显示需求与材料提交入口；已有审核结果的任务提供“查看报告”主操作，重新生成收进折叠区，保留生成记录。
- 首页、任务空态与设置说明去掉过时的“先存需求草稿”文案。自然语言提交、五角色自动协作、审核、报告文字修改与复审、Markdown/PDF交付继续使用原入口。

## 保留的后台约束

需求版本字段仍用于防止旧页面覆盖修改及绑定执行范围；材料版本、完整来源记录、运行记录和已审核报告历史均保留。Data仍自动计算数据，Checker仍自动校验，Manager仍最终验收。删除的是额外的人工页面，不是自动协作中的统计或审核功能。现有统计与草稿API保留兼容；本版不触碰数据库历史。

## 验证

Ruff检查和格式检查、全量Python858项测试、前端API13项测试、TypeScript/Vite构建。页面验收检查待生成、已合格、报告查看与下载入口、重新生成区域及手机宽度布局；不调用付费模型，不重复生成用户报告。未提交输入的离开提示与取消后内容保留已实际检查；390px手机宽度下页面宽度为390px，无横向溢出。具体发布以本版PR的最终CI结果为准。

本版调整办公使用界面，不将本地单用户系统声称为已经完成公网多用户部署。
