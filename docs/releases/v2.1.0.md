# v2.1.0 季度办公案例与五角色职责复核

2026-10-20。对应[开发计划](plan-v2.1.0.md)与[独立审查](../review-v2.1.0-agents.md)。

## 结果

正常8520工作台原有“使用系统本地样例数据（虚构）”现提供较大的季度材料，仍需用户明确勾选，不自动填充首页。新建任务可先“取消全部选择”，防止旧小案例与新案例混用。历史报告、data/demo原件及课程实验报告保持不变。

- 技术部：四个业务组、24名匿名人员、65个虚构企业工作日、1560考勤人日；12个项目的36条月末快照，6个完成项目；42项关联成果。包含请假、缺勤、迟到、超计划工时、待验收及暂停项目。
- 行政部：6类服务、216份反馈，每月72份；204份有效、12份明确无效，同一1–5量表均分810÷204≈3.970588。保留渠道、服务单、匿名提交者、意见与无效原因。
- 对应TXT说明含业务背景、依赖风险、复盘与下一步计划，随本地接口授权经普通材料流程冻结，按部门/期间筛选后传入Writer。接口只允许固定白名单，不读取任意URL或本机文件。
- 全部是明确标注的虚构材料，采用标准库和固定SHA算法可逐字节重建；[材料说明](../../data/office-cases/README.md)列出精确预期、字段边界、数据哈希和可复制需求。

## 五角色实际职责

Manager接收需求并拆解；Planner消费Manager任务生成大纲及数据维度；Data按规划读取授权版本并调用确定性工具；Writer接收大纲、事实与文字依据；Checker执行程序校验及模型审核，意见回传Writer有界修订；最后Manager接收审核结果决定验收。五种角色正常执行六次节点，末尾Manager不是新增角色。

本次审查未发现伪协作链，修正两项扩大量材料时的边界：

1. 文字每片段1000字/总5000字限制原先静默截短或省略。现记录选取/截短/省略数量，同步Data、Writer、Checker、Manager及事件、导出限制；结构化统计仍全量。
2. 新快照用grouped-v1来源显示，把连续行压缩为准确范围，同源文字列出每个片段到行号映射，完整SHA只按组显示。统计JSON仍保留全部行级引用；旧快照继续原渲染，避免既有合格内容失效。

没有显式声明人员×排班日期时，即使输入1560条记录，自动流程的整体出勤率和覆盖率仍未定义；只能报告已提供样本的95.3486%。原始实际12190.5小时不等于计入出勤11899.5小时，超计划291小时不进入分子。迟到、缺勤等扩展列供原始记录核查，没有伪称新增月度、服务类别等Agent统计功能。

## 使用

仍打开 http://127.0.0.1:8520 ，新建报告→取消全部材料选择→勾选本地样例→粘贴[需求文本](../../data/office-cases/README.md)→选择执行模式→开始协作。旧报告按冻结来源回看，新案例必须新建运行才会使用新数据。不切换空间或端口。
