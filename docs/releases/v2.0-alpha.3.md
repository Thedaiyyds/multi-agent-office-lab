# v2.0-alpha.3 数据统计发布验收

## 实际行为

正常报告工作区从材料库多选已确认版本，按材料分类推导统计组，也可调整；计算绑定已保存的部门、半开期间、草稿版本和选中材料，统计不调用模型。结果显示数值、公式、原值、范围限制、材料版本/哈希/原始行定位。修改草稿后旧快照标为过期；刷新恢复历史，不重新计算。

后端只读取不可变全量rows_json，不使用20条预览。跨文件同业务键完全相同合并来源，冲突使本次指标无效；同系列多个历史版本要求选一。考勤缺值/零分母与真实0分别处理；满意度不跨量表混算。没有名册/日期时只能显示样本指标，不能冒充季度整体。

## 使用与剩余工作

继续使用8520。上传确认材料→新建或打开报告→选择材料与统计组→“整理并核对数据”→展开指标来源。可选清单是人员编号列表与排班日期列表的笛卡尔积，上限20000人日；只代表用户明确声明范围。

本阶段尚未接通自然语言执行、五角色、审核返工、PDF和新版Markdown交付；按已授权计划继续alpha.4及后续，不能把旧版离线验收当新版完整功能证明。
