# v2.0-alpha.2 材料接入发布验收

日期：2026-10-16。功能依据：[指导书功能基线](../proposals/v2.0-review/functional-baseline.md)。保留alpha.1界面和架构，本次完成材料阶段；新版完整五角色和Markdown/PDF输出尚未交付。

## 本版行为

- 本地TXT、CSV、DOCX正文/普通表格可解析、预览并标记行/段落/表格位置；结构化材料提供必需及可选字段映射，确认时全量校验。
- 日期、数字、量表、重复业务记录、文件格式及容量异常提供具体问题；确认前不会进入材料版本列表。
- 确认保存原始字节、哈希、映射、部门和期间；相同内容与设置复用已有版本，同名同分类新内容递增版本。下载与查询校验normal/demo空间。
- 演示案例从帮助页手动加载，模拟接口只提供固定本地数据，不接受任意URL；页面不自动填实验案例。本地接口响应冻结为CSV后走相同预览/确认流程。
- 独立演示启动脚本使用8530、outputs/demo；正常服务使用8520、outputs/workbench。合成案例文件只读，运行数据不提交Git。

## 协作与审查

材料后端、前端、独立质量Agent分工，主协调者负责契约、集成、浏览器与发布。见[计划](../plan-v2.0-alpha.2.md)和[独立审查记录](../review-v2.0-alpha.2.md)。发现并修复进度单位、可选映射、DOCX条数上限及批量案例确认前预检等问题，最终无剩余阻断项。

## 使用及限制

按[演示教程](../demo-v2.0-alpha.2.md)启动和操作，示例源码在data/demo。行政案例可另行手动导入，不自动混入技术案例。

当前仅材料接入和草稿保存；统计为alpha.3，五角色编排为alpha.4，报告审核完善及Markdown/PDF为alpha.5。旧版LangGraph验收证明旧流程未回归，不能证明新版编排已完成。

预览最多20条，确认校验全量；单文件10MiB，最多20000条明细，DOCX解压后50MiB。DOCX图片/复杂文本框不提取并提示，宏、嵌入对象和外部关系拒绝。此阶段没有材料删除、暂存清理或跨文件统计合并。重复加载仅对已确认版本去重，导入草稿和暂存原件会保留；批量案例先全量预检，各材料分别事务确认，不承诺进程中断时整个案例原子提交。

本页记录本地验收事实。GitHub检查通过后才合并，PR与标签指向本版实际提交。
