# v2.0-alpha.1 发布与实际验证

日期：2026-10-16。阶段：新版草稿工作台，等待用户审查界面方向。

## 本版实际能力

- React / TypeScript / Tailwind 独立业务界面；工作台空状态、报告列表搜索、新建与编辑需求草稿。
- FastAPI / SQLite 真实持久化，刷新和重启保留数据。报告含版本号，过期页面保存返回409；创建请求有持久幂等键。
- 正常和演示空间从接口到数据库隔离；演示入口需要显式进入，不自动加载课程案例。
- 窄屏导航和单栏表单、字段标签、可见焦点、保存中防重复/输入覆盖、离开前未保存确认。
- 系统状态只返回模型是否已配置；本版不请求模型。材料、统计、五角色运行、审核和多格式导出尚未开放。

## 协作审查

A 后端角色实现 API 和39项边界测试；B 前端角色实现界面交互；C 质量角色独立执行回归和源码交叉检查；主协调者负责依赖、入口、集成、浏览器和Git发布。

实际发现并修复：源码版本与安装版本不一致；保存过程中输入被覆盖；章节长度前后端不一致；浏览器后退绕过未保存提醒；409后继续编辑隐藏恢复入口；卸载后旧请求响应跳转；移动隐藏导航仍可聚焦。Vite安装审计发现高危漏洞，升级至6.4.4兼容补丁后审计为0。

## 启动与后续

在仓库根目录运行 `bash scripts/start_workbench.sh`，打开 http://127.0.0.1:8520。已有构建时 `uv run --locked office-workbench`。数据位于 outputs/workbench，退出终端不会删除；安装与构建产物不入Git。

按说明书第14节，用户认可主要界面后进入alpha.2，实施材料导入、预览、字段映射和版本。本版尚未实现审批修订历史，因此草稿版本号只用于并发保护，不宣称能够逐版回看。系统设置当前只读，不提供网页编辑密钥。
