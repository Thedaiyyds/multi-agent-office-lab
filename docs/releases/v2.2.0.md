# v2.2.0：直接读取材料文件与侧边预览

按用户确认的实验实现方式调整材料链路：导入文件后保存在本地工作目录，DataAgent执行时调用文件工具解析、校验并统计，不再读取数据库中的材料明细缓存。五角色职责与Markdown/PDF交付流程保持原有行为。

## 文件与数据库的职责

- 原文件位于 `outputs/workbench/materials/`。新导入文件保留普通长度的原文件名（超长Unicode文件名使用兼容磁盘名称，显示名与下载名不变），放入独立子目录，防止同名覆盖；已有文件路径不搬动。
- SQLite保留文件索引、分类、字段对应关系、部门及期间、校验值等元数据。`imports`、`material_versions`移除`rows_json`列，元数据中移除预览正文。表名和稳定ID保留以兼容历史报告引用。
- 上传预览、导入确认、材料查看、DataAgent运行和兼容统计接口，均按需读取实际文件，解析结果只在本次操作内存中使用。
- 报告统计、引用、运行过程和生成结果仍然持久化，这是报告结果记录，不是材料原文缓存。旧报告结果不重新生成，不因本次迁移更改。
- 文件缺失、内容被修改或校验失败时明确报错，不使用旧数据库内容兜底。修改材料后请重新导入确认。
- 本地模拟接口仍提供指导书要求的另一种输入方式，其返回数据保存为文件后，由同一个读取工具整理。

## 材料查看

点击任意文件即在右侧打开预览面板，不再把详情追加到列表末尾。面板有固定标题和关闭按钮，内容独立滚动、表格可横向滚动，支持Escape关闭、键盘焦点限制及关闭后返回列表按钮；手机上占满可用宽度。

列表默认展示同名同分类最新文件，可勾选“包含历史文件”。去掉显眼的材料版本号，以导入时间区分历史文件；保留文件原件和来源关联。

## 迁移与验证

首次启动自动去除旧材料内容缓存，保留原件、索引ID和字段配置；迁移可重复执行。升级前备份SQLite数据库及原件，不删除已有文件。

离线回归覆盖直接读文件、旧缓存迁移、文件变化/缺失导致Data阶段停止、TXT/CSV/DOCX读取、模拟接口、五角色全流程及Markdown/PDF导出；不调用付费模型。本地验证：863项Python测试、13项前端API测试、Ruff检查及TypeScript/Vite构建通过，另有8项离线验收场景全部符合预期。实际浏览器验证1360×900桌面和390×844手机布局、预览独立滚动、Escape关闭、焦点返回列表及历史文件切换。已有14份材料均能读取预览和下载，升级前30个材料及报告文件SHA-256一致，完整材料缓存列及缓存预览已移除。

回退旧版本代码时，需要恢复升级前的数据库备份；旧版本依赖已删除的缓存列，不能直接使用新数据库。当前本地备份在`outputs/backups/`，不提交Git。
