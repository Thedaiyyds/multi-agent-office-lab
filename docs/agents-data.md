# Data Agent 的权限与运行契约

`run_data_agent(requirements, data_root, session)` 接受已经校验的需求，最多请求模型两次、实际执行数据工具一次。工具调用输出上限为 128 token，摘要输出上限为 192 token；共享 Session 关闭思考和重试并限制总预算。

模型必须调用唯一的 `run_data_tools` 函数，仅提供 `department`、`start_date`、`end_date` 三个字符串字段。日期为严格 ISO 格式，全部参数必须与 Requirements 精确一致。代码拒绝未知工具、多工具调用、重复 JSON 字段、非法 ID、额外字段、部门或日期越权。数据目录由调用方绑定；模型无法更改路径。

执行沿用 v0.2 的全量校验、最新快照去重和确定性统计。`tool_execution` 事件在真正执行之后记录三个授权参数及安全结论，不记录路径、原始材料、隐藏思考或原始错误。执行失败不重试。全量校验失败返回 `needs_input`，没有统计指标，也不会再次请求模型生成摘要。

正常数据和 `no_data` 均将确定性结果保留在 `DataAgentResult.data` 中。第二轮给模型的工具结果只含指标 ID、值、单位、来源 ID、去重后的异常代码及未筛选问题材料的范围标记；原始问题全文不传入模型。`no_data` 保留四项指标中的零计数和完成率 `null`，不能把没有分母解释成 0%。

模型只生成 `{summary, limitations}`，由本地 Pydantic 校验。摘要自然语言的每个事实不在此阶段穷尽验证；后续 Writer 与 Checker 应以 `data` 的指标和来源作为权威依据，不能用模型摘要替代统计结果。模型摘要不能触发第三次请求或其他工具。

离线测试使用队列模拟模型响应，数据工具读取真实样例文件；覆盖正常统计、空结果、全量校验失败、工具越权、重复参数、工具异常、截断响应和非法摘要。测试不会读取 `.env` 或请求真实模型服务。
