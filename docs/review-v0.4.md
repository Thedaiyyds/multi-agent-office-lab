## 独立验收的证据

`tests/test_workflow_integration.py` 使用真正的角色函数和 StateGraph，通过本地 MockTransport 记录实际 HTTP 请求；不替换图编排，也不调用真实 API。

- 研发部 Q2、研发部 Q1、市场部 Q2 分别得到对应权威统计；实际 Manager 需求、大纲的 `part_1` 等非 v0.3 示例编号、Data 指标和 Writer 草稿传递至后续节点。
- 自定义章节和显式 ISO 日期原样进入实际大纲与草稿；`provided` / `simulated` 来源由调用方注入，保持跨节点一致。
- 修改实际 CSV 中 P003 的状态和进度后，完成项目数从 2 变为 3、完成率变为 1；Writer 事实和最终报告随工具结果变化，证明未复用固定统计夹具。
- 缺需求在 Manager 终止；无数据和缺文件在 Data 终止；模型 HTTP 错误、非法 JSON、超时、请求预算不足及本地工具异常均保留已执行节点并停止后续请求。
- Data 模型尝试更改部门、起始日期或添加路径，均在工具执行前拒绝，模型不能扩大数据范围或指定读取路径。
- Writer 错指标或漏章节时，脚本 Checker 刻意返回 `passed=true`，程序校验仍输出 `review_failed`；保留“审核未通过”草稿且没有 report.md，本版不自动返工。
- 核对实际节点开始/完成事件顺序、统一 run_id、节点输入输出快照、一次真实本地工具执行和非负耗时；业务存档不包含测试密钥或原始错误内容。
- 禁止加载环境配置后，离线完整链路仍然运行成功，确保不读取用户 API 密钥。

## 审查结论及验证范围

当前编排使用前一步真实输出；Writer / Checker 接收独立拷贝，不能修改权威数据及先前审计记录。导出使用独立 run_id 目录，拒绝覆盖，只有已通过 Checker 且再次通过本地事实复核的 completed 运行产生 report.md。架构和时序图见 `architecture-v0.4.md`，图中不包含未来版本的自动返工循环。

离线响应是脚本数据，验证流程和程序约束，不证明模型自然语言理解或叙述真实性。程序检查四项结构化指标、单位、来源、章节和渲染一致性；自然语言中未结构化的事实还依赖模型审核及人工阅读。真实模式的请求与 token 用量必须依据实际调用记录另行验收。JSON 和终端记录不冒充实验运行截图。
