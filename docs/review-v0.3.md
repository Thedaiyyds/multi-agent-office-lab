## 发现与修复

1. Checker 数值比较可能把布尔值 True 当成 1。改为严格 int/float，回归覆盖权威值 1 与变异布尔值。
2. 模型正文可包含 Markdown 标题或 HTML，使可见章节与结构化章节不同。统一渲染将文本合并为单行并转义结构字符，正文/建议/来源/标题均覆盖，注入测试及复核通过。
3. 极大整数的有限性校验可能抛 OverflowError。共享 JSON 校验静态处理数值溢出、坏类型、重复 JSON 字段和非有限值；Data 摘要轮也统一使用共享解析。
4. 固定样例对 provided 来源仍写“模拟统计”。协调者按调用方来源声明生成说明；无匹配数据的草稿不生成统计事实。独立入口测试覆盖两类情况。
5. Manager/Planner 的独立样例不应依赖本地数据文件。协调者按角色懒加载固定数据，测试禁止这两个入口调用数据工具仍能通过。

未发现剩余阻断问题。核心事实、来源及结构由程序检查；部门子串、显式日期 grounding 与模型语义审核都有覆盖边界，不声明完全验证任意自然语言。实际测试数量、模式和真实服务用量见 [验证记录](validation-v0.3.md)。
